# 広告クリエイティブ制作ブリーフ

## 目的
事前登録LP（`public/<slug>.html`）へ誘導する広告用の画像を作る。Instagram / Facebook / TikTok のフィード・ストーリーズと、Google のディスプレイ・P-MAX で使う。

## 作るもの（1サービスにつき3枚）
| ファイル名 | サイズ | 用途 |
|---|---|---|
| `ads/creatives/<slug>-square.png` | 1080×1080 | Instagram / Facebook フィード |
| `ads/creatives/<slug>-story.png` | 1080×1920 | ストーリーズ / リール / TikTok |
| `ads/creatives/<slug>-landscape.png` | 1200×628 | Google ディスプレイ / Facebook リンク広告 |

元にしたHTMLは `ads/creatives/src/<slug>-<種類>.html` に置く（あとで文言を直して撮り直せるように）。

## 作り方
- 1枚ずつHTMLで組み、Playwright でその解像度ちょうどにスクリーンショットする（`NODE_PATH=$(npm root -g) node <script>`、`executablePath: '/opt/pw-browsers/chromium'`、`deviceScaleFactor: 1`、フォント読み込みを待ってから撮る。Google Fonts は読み込める）。
- **LPと同じ世界観で作る**。担当LPの HTML を読み、色・フォント・描き込んだSVGイラスト（ヒーローの主役の絵、アイコンの器など）をそのまま流用してよい。広告を見た人がLPに来たとき「同じものだ」と分かることが大事。
- 絵文字や Fluent 3D 画像は使わない（オーナーが「AIっぽい」と嫌った）。
- 文字は少なく、大きく。スマホで一瞬見て読める量にする:
  - メインコピー（下の指定のもの。改行位置は調整してよい）
  - サブコピー1行（任意）
  - 「事前登録受付中」のバッジ
  - ボタン風の「無料で先行登録」
  - サービス名（ロゴ）
- ストーリー（1080×1920）は、上下それぞれ約250pxを文字を置かない余白にする（アプリのUIで隠れるため）。
- **嘘を書かない**: 架空の実績・利用者数・お客様の声・「No.1」・「必ず」「絶対」などの断定は禁止。料金を載せるならLPと同じ予定価格で「予定価格」と添える。商品の画面例を載せるなら「表示例」と小さく入れる。
- 背景を単色ベタにせず、LPの柄（設計図の線、方眼、原稿用紙、レーダーなど）や構図で「作り込んだ」見た目にする。

## メインコピー
| slug | サービス名 | メインコピー | サブコピー案 |
|---|---|---|---|
| pet | うちの子アトリエ | うちの子の写真が、アクスタに。 | 注文前に、仕上がりを無料でプレビュー |
| kaitai | 解体見積メーカー | 坪数と構造で、内訳つき見積書。 | 解体工事の見積書を、現場でつくる |
| eisei | 衛生管理者 合格ドリル | 試験日から逆算して、毎日の出題を。 | 第一種・第二種衛生管理者の試験対策 |
| koumuin | 公務員面接トレーナー | 面接カードから、深掘り質問を。 | 公務員試験の面接練習をAIで |
| receipt | レシートまるごと申告 | 1年分のレシート、まとめてデータに。 | 確定申告の準備を、撮るだけで |
| taikyo | 退去前チェックパック | 退去の立ち会い、その前に。 | 退去費用で損しないための準備 |
| watch | ページ見張り番 | 見たいページの更新、LINEに届く。 | 補助金・公募の新着を見逃さない |
| shibou | 志望理由書コーチ | 書き直さない。問い返す添削。 | 総合型選抜・推薦の志望理由書に |
| renai | メンズ恋愛ナビ | このLINE、どう返す？ | いつでも相談できるAIコーチ |
| souzoku | 相続やることナビ | 相続の手続き、いつまでに何を。 | やることと期限を、一覧に |

souzoku は落ち着いた、配慮ある表現にする（派手な色や動きを連想させる表現は避ける）。renai は相手を尊重するトーンを保つ。

## 確認
全部撮ったら、各PNGを1回ずつ目で見て、文字の切れ・はみ出し・読みにくさが無いか確認し、あれば1回直して撮り直す。

## 報告
作ったファイルのパス一覧と、各サービスのビジュアルの方向性を1〜2行ずつ。
